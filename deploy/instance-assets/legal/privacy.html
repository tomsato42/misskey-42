プライバシーポリシー

42times (https://42times.kinachan.com、以下「本サービス」) の運営者 tomsato (以下「運営者」) は、利用者の情報を次のとおり取り扱います。本サービスは 42 の学生が個人で運営する非公式のサービスで、一般社団法人 42 Tokyo および 42 Network が運営するものではなく、これらの団体とは関係がありません。

1. 取得する情報

  1. 42 intra から取得する情報: 42 のユーザー ID、login、キャンパス、ピシンの年月、42cursus の開始日とレベル、Blackhole の日付、コアリション、課題の状態・点数・合否・チームのメンバー、達成したクエスト。ログインのときと、およそ 1 時間ごとに 42 API から取得し直します。42 のパスワード、メールアドレス、本名、顔写真は保存しません。
  2. 利用者が入力・投稿する情報: プロフィール、ノート、リアクション、フォロー、チャットのメッセージ、ペア募集、カレンダーのイベント、アップロードしたファイル、パスキーやパスワード (暗号学的ハッシュ)、各種の設定。
  3. 自動で記録される情報: ログインの日時、ログインや API の利用のときの IP アドレス、ブラウザーの種類などのリクエスト情報、アクセスログ、プッシュ通知の購読情報。

2. 利用目的

  1. アカウントの作成、ログイン、本人確認のため
  2. レベル・キャンパス・ピシン・入学時期・コアリションのロールを自動で付け、プロフィールやタイムラインに表示するため
  3. ペア募集で取り組める課題を判定し、課題の結果を通知し、利用者が選んだときに結果をノートに表示するため
  4. 投稿、チャット、カレンダー、通知など、本サービスの機能を提供するため
  5. 不正利用・荒らし・規約違反への対応、障害の調査、セキュリティの確保のため
  6. 問い合わせへの対応、重要なお知らせのため

3. 公開される情報

本サービスの内容は、ログインした利用者だけが見られます。ほかのサーバーとの連合はしていません。ただし、次の情報はログインした利用者に公開されます。

  • ユーザー名、プロフィール、公開範囲に応じたノートとファイル
  • 42 の login とピシンの年月
  • 自動で付くロール (レベル、キャンパス、ピシン、入学時期、コアリション)。これらは利用者が外すことはできません
  • 利用者がノートに付けた課題の結果 (点数、合否、チームのメンバーの login)

Blackhole の日付は保存しますが、ほかの利用者には表示しません。

4. 第三者への提供

法令に基づく場合、人の生命・身体・財産の保護に必要で本人の同意を得ることが難しい場合を除き、本人の同意なく個人情報を第三者に提供しません。広告や解析のサービスには送りません。

6. Cookie とブラウザーの保存領域

ログインの維持、画像をログインした利用者にだけ表示するための署名付き Cookie、表示設定の保存に、Cookie とブラウザーの保存領域を使います。広告や行動の追跡には使いません。

7. 保存期間と退会

  1. 利用者は設定画面からアカウントを削除できます。削除すると、ノート、ファイル、チャットなどは順次消去されます。
  2. 同じ 42 アカウントでの二重登録や、凍結された人の再登録を防ぐため、削除したアカウントのユーザー名と 42 のユーザー ID は残ります。再登録を希望する場合は運営者に連絡してください。
  3. バックアップは毎日作成し、7 日分を保存します。削除した情報も、最大 7 日間はバックアップに残ります。
  4. サインイン履歴はアカウントを削除するまで、アクセスログは障害や攻撃の調査に必要な期間 (原則として 90 日以内) 保存します。
  5. 42 intra との連携をやめたい場合は、intra の設定で本サービスのアプリへの許可を取り消してください。

8. 安全管理

通信の暗号化 (HTTPS)、管理権限の限定、アップロードされたファイルのアクセス制限、バックアップなどの対策をとります。チャットを含む投稿はエンドツーエンドで暗号化されていないため、運営者は障害対応や規約違反の調査に必要な範囲で内容を確認することがあります。

9. 開示・訂正・利用停止の請求

本人から、保有している個人情報の開示・訂正・削除・利用停止の請求があった場合は、本人確認のうえで法令に従って対応します。申し出は下の窓口へお願いします。

10. 未成年の利用者

本サービスは 18 歳未満の方を対象としていません。18 歳未満の方の情報を取得したと分かった場合は、アカウントと合わせて削除します。

11. 改定

このポリシーを変えるときは、本サービスのお知らせで事前に告知します。
